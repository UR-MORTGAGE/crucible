# Crucible — roadmap (the pitch's "where this goes")

Crucible ships as **one sharp wedge**: adversarial, transparent underwriting that
turns a denial into a cited **Path to Yes**. The next three products ride the
*same engine* — that's the platform story judges reward under "startup potential."

## The wedge (built — this is the hackathon submission)
**Glass-Box "Path to Yes."** Adversary vs. Advocate on a live loan; the bench rules
on the cited record. Hybrid router = local MI300X + Fireworks. Compliance firewall
(cited-or-silent, Reg-B adverse-action) as a feature, not a burden.

## Roadmap — same engine, wider surface

### 1 · Guideline Simulator  *(nearest — already latent)*
"What-if" the loan: change down payment, pay down a card, add a co-borrower, switch
program → instant cited answer with the DTI/LTV/reserve math. **The editable loan
file + live preview in the demo is this in miniature.** Ship = expose the what-if as
a first-class flow with side-by-side scenario compare.

### 2 · Living Loan  *(continuous)*
Stop treating a mortgage as a one-time event. Run Crucible continuously as rates,
finances, and guidelines change; ping the borrower the moment a refi / recast / PMI
drop / restructure becomes fundable. Ship = a scheduler + a delta watcher on top of
the engine. Category shift: lending from event-driven → continuous.

### 3 · Fiduciary Advocate  *(alignment flip)*
Generalize the Advocate to shop across investors and products *for the borrower*,
with every conflict disclosed. Ship = widen the Advocate + a real investor/overlay
matrix. Category shift: advice from commission-conflicted → aligned.
